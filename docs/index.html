Introduction

IPL (Intelligent Programming Language) is a revolutionary programming language that integrates AI models directly into the compilation pipeline. Unlike traditional code suggestion tools, IPL uses AI at the compiler level to understand, analyze, and optimize code during compilation.

🧠
Neuro-Symbolic

Combines neural language understanding with symbolic verification for intelligent compilation.

🔒
Security-First

Built-in mathematical firewall and zero-trust taint tracking for comprehensive security.

Key Differentiator: IPL is intelligent at the compiler level, not the code suggestion level. AI transforms the compilation process itself.

Installation

Quick Start
pip install ipl-lang
ipl run examples/01_intelligent_variables.ipl

Docker Installation

# Core language only
docker build -f Dockerfile.core -t ipl-lang-core .
docker run -p 8000:8000 ipl-lang-core

# With local AI (Ollama)
docker build -f Dockerfile.ai -t ipl-lang-ai .
docker run -p 8000:8000 ipl-lang-ai

AI Provider Options

🖥️ Local AI (Ollama)
pip install ipl-lang
# Install Ollama
curl -fsSL https://ollama.com/install.sh | sh
ipl run script.ipl --ai-provider ollama --ai-model qwen2.5-coder:0.5b
☁️ Cloud AI (OpenAI)
pip install ipl-lang openai
export OPENAI_API_KEY=your_key
ipl run script.ipl --ai-provider openai --ai-model gpt-4
⚙️ Custom AI

Implement your own AI provider by following the integration architecture.

Syntax Guide

// Semantic variables with automatic type extraction
let price: Currency = "ninety-nine bucks and 50 cents"
let review: Sentiment = "Super fast and rock solid!"
let age: Int = intent "Extract user_age twenty-five" as Int

// Security operations
let clean_age = sanitize(age)
db_write("users", clean_age)

// Functions
fn calculate_tax(amount, rate) {
    return amount * rate
}

// Adaptive output formatting
print invoice for "executive"  // Business summary
print invoice for "developer"  // Technical details

Basic Syntax Elements

Element Syntax Description
Variables let name = value Variable declaration
Typed Variables let name: Type = value Typed variable declaration
Functions fn name(args) { } Function definition
Print print expression Output to console
Comments // comment Single-line comments
